# NaviFix — Windows Installer

This directory contains everything needed to build the NaviFix Windows `.exe` installer.

## What Gets Built

| File | Purpose |
|---|---|
| `NaviFixApp.exe` | Native Windows window (PyWebView / WebView2) |
| `NaviFixTray.exe` | System tray icon manager |
| `NaviFix-X.Y.Z-setup.exe` | Final installer shipped to users |

## Prerequisites (Windows build machine only)

1. **Python 3.11+** — https://python.org
2. **PyInstaller** — `pip install pyinstaller`
3. **Inno Setup 6.3+** — https://jrsoftware.org/isinfo.php  
   *(Add `iscc` to your PATH during installation)*
4. **Docker Desktop** — for testing the installer locally

## Building the Installer

```powershell
# From the repo root, on a Windows 11 machine:
.\installer\build.ps1

# Build a specific version:
.\installer\build.ps1 -Version "1.2.0"

# Output:
#   installer\dist\NaviFix-1.2.0-setup.exe
```

## Releasing an Update

1. Make your code changes and test them
2. Run `.\installer\build.ps1 -Version "X.Y.Z"`
3. Upload `dist\NaviFix-X.Y.Z-setup.exe` to your release server
4. Update `version.json` on your server:
   ```json
   {
     "version": "X.Y.Z",
     "release_notes": "What changed in this version",
     "download_url": "https://your-server.com/releases/NaviFix-X.Y.Z-setup.exe",
     "mandatory": false
   }
   ```
5. All running NaviFix installs will notify users within 1 hour

## Directory Structure

```
installer/
├── build.ps1          ← One-command build script
├── setup.iss          ← Inno Setup installer definition
├── version.json       ← Upload this to your update server
├── app/
│   ├── main.py        ← PyWebView native window app
│   ├── splash.html    ← Loading screen
│   └── requirements.txt
├── tray/
│   ├── tray_app.py    ← System tray manager
│   ├── updater.py     ← Auto-update checker
│   └── requirements.txt
├── launcher/
│   ├── start.ps1      ← Start containers + open window
│   ├── stop.ps1       ← Stop containers
│   └── first_run.ps1  ← First-time setup (keys + image pull)
├── assets/
│   ├── icon.ico       ← App icon (replace with your own)
│   ├── wizard_banner.bmp   ← 497x58 px installer banner
│   └── wizard_logo.bmp     ← 55x58 px installer logo
└── build/             ← Generated by build.ps1 (gitignored)
└── dist/              ← Final installer output (gitignored)
```

## Customising

| What to change | Where |
|---|---|
| App name | `setup.iss` → `#define AppName` |
| Publisher | `setup.iss` → `#define AppPublisher` |
| Update server URL | `tray/updater.py` → `UPDATE_CHECK_URL` |
| Backend port | `docker-compose.yml` + `app/main.py` → `BACKEND_URL` |
| Icon | Replace `assets/icon.ico` |

## Notes

- The `backend/` source code is **not modified** by any installer component.
- Docker containers run Linux — `gunicorn` and `eventlet` work as-is.
- WebView2 (required by PyWebView) is **pre-installed on all Windows 11 machines**.
- The installer requires **admin rights** to write to `C:\Program Files\`.
- Silent install for enterprise deployment: `NaviFix-1.0.0-setup.exe /SILENT /NORESTART`
